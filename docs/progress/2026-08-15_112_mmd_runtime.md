## 한 것

- `AvatarSourceRuntime` 에 `"mmd"` 추가 — 어댑터 레지스트리 3번째 등록
  (`AvatarRegistry.ts:9` 의 "third runtime lands" 예언이 이뤄진 날).
- `MmdAdapter` + `mmd/MmdStage`(babylon-mmd 1.3.0, dynamic import) —
  머티리얼=레이어 가시성 토글, 모프=파라미터, VMD=애니메이션, 블링크/호흡
  아이들, SPR WASM 물리(실패 시 리지드 폴백), 카메라 캡처/리셋, 썸네일.
- `capabilities.selfHostedView` — usePuppet/PuppetCanvas 가 Pixi 생성을
  건너뛰는 additive 분기. 2D 경로는 바이트 동일.
- parseBundle `buildMmdLoadInput`(blob URL 재작성 없음 — referenceFiles 방식),
  다중 .pmx 는 최대 크기 선택 + 경고.
- Animation 탭 MMD 섹션(`MmdSections.tsx`): VMD ▶/⏹ · 모프 슬라이더(패널
  그룹) · GoEmotion→모프 맵 · lip-sync 모프 · 카메라 구도 저장.
- Export: buildModelZip/passthroughBake 에 `sidecar.mmd` 블록 +
  `animationConfig.{mmdCamera,lipSyncMorph}` (schemaVersion 2 유지).
- `/poc/mmd` 스모크 페이지.

## 검증

- headless chromium(SwiftShader) E2E: zip 업로드 → IDB 저장 → `/edit/<id>`
  렌더("mmd PMX" 헤더) → Layers 45행 · Up_Hat 토글 → Animation 탭에서
  joy→笑い 매핑 + 카메라 저장 → IDB `puppetAnimationConfig` 라운드트립 확인.
- `pnpm typecheck` / `pnpm lint` / `pnpm build` 클린.

## 함정 노트 (다음 사람을 위해)

- Babylon `Bone.rotationQuaternion` getter 는 **복사본** — mutate 는 무효,
  반드시 setter 대입.
- `createMmdModel` 은 기본으로 metadata 를 **trim** 한다 — 모프/머티리얼/
  스켈레톤 카탈로그는 그 **전에** 캡처.
- WASM 은 멀티스레드 빌드(MPR)가 아니라 **SPR** — COOP/COEP 없는
  `/avatar-editor` 프리픽스·오버레이에서 SharedArrayBuffer 가 없다.
