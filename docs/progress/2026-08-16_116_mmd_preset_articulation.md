# 116 — 프리셋 관절 고도화: 체인 관절·지면 설계·VMD 축 실증 (v0.6.1)

> 2026-08-16 · "너무 이상하게 움직여 관절을 제대로 표현하지 못하네" 대응

## 실증으로 확정한 사실 (전부 vmd-play 프로브)

1. **다리 IK**: センター 하강/수평 이동은 무릎이 자연스럽게 굽는다(증명).
   센터 '상승'은 다리만 펴지고, **足ＩＫ 위치 트랙은 이 파이프라인에서
   신뢰 불가**(상수-포즈에서 발이 끝내 안 뜸) → **전 프리셋 지면 설계**
   원칙 채택. '신나는 점프'는 무릎 펌핑 지면 바운스로 재설계.
2. **VMD 축 의미는 Babylon 직접 본 세팅에서 이전되지 않고, 단일 미러
   규칙으로도 정리되지 않는다**(부호 조합 A/B 매트릭스 검증). 철칙:
   새 포즈는 반드시 vmd-play 프로브로 파일-공간에서 검증.
   확정 파일-공간 사실: 腕 roll+ = 오른팔 하강 · 몸통 pitch− = 앞으로
   숙임 · 든-팔 인사 = 肩−0.25 + 腕{pitch+0.45, roll−1.15} + ひじ+1.0
   (pitch −0.45 는 막대팔이 된다).

## 관절 체인화

armChain(肩 25%→腕→ひじ 기본 굽힘 0.06+) · headChain(首 35%→頭) ·
下半身 카운터 — 9종 전부 적용. 샘플링 3f→2f. 손 인사는 팔꿈치가
또렷이 접히는 포즈로 완성.

## 정지 잔류 버그

모션 정지 시 본이 마지막 프레임에 얼어붙던 문제(점프 중 정지 = 공중
포즈 잔류) → stopAnimation 에서 skeleton.returnToRest() 후 절차적
아이들이 재구축.
