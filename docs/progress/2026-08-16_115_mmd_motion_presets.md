# 115 — 내장 모션 프리셋: 수학적 저작 VMD 라이브러리 (v0.6.0)

> 2026-08-16 · plan: [10_mmd_3d_runtime.md](../plan/10_mmd_3d_runtime.md)

## 배경

배포되는 VMD 모션은 거의 전부 재배포 금지 약관이라 동봉 불가. 그래서
**프리셋을 수학적으로 저작**한다 — `scripts/generate-motion-presets.mjs`
(커밋된 결정론적 생성기, `pnpm gen:motions`)가 eased 본 채널을 VMD
키프레임으로 샘플링해 `public/motions/*.vmd` + `manifest.json`을 만든다.
100% 자사 저작물 = repo 라이선스로 자유 배포.

## 프리셋 9종

잔잔한 아이들(8s) · 리듬 아이들(4s) · 손 인사(5s) · 정중한 인사/절(5s) ·
끄덕끄덕(2.5s) · 도리도리(2.5s) · 신나는 점프(4s) · 두리번(6s) ·
리듬 스윙(8s). 전부 루프-이음새 무결(시작=끝=차렷) + 팔 내림 키 포함.

## UI

Animation 탭 Motions 섹션에 "내장 프리셋" 블록: ▶ 미리보기(스테이지에만
등록, 리로드 시 소멸) / **+ 추가**(IDB 영속 → 모션 목록·아이들 지정·
export·Geny 동기화 합류, "추가됨" 상태 표시).

## 좌표계 실증 기록 (제작 시 필수 지식)

- **pitch 양수 = 뒤로 젖힘/올려봄, 음수 = 앞으로 숙임** (모델이 −Z 를
  보는 LH 공간; 첫 절 프리셋이 뒤로 넘어가며 발견)
- 팔꿈치 fold 평면은 든 팔에서 아래-앞을 향함 → 접은 손 인사는 "축 처진
  손"으로 보임 → **팔 전체를 흔드는 아이돌식 인사**로 설계
- quatYPR 는 Babylon RotationYawPitchRoll 과 동일 조성(YXZ)

## 검증

vmd-play 프로브(특정 초 정지 스크린샷)로 절/인사/점프/스윙 포즈 시각
확인. UI E2E: 프리셋 블록 렌더 → 손 인사 미리보기(1s 6.95% 픽셀 변화) →
잔잔한 아이들 + 추가 → 목록 등장 → 아이들 지정 → export zip 에
motions/idle-breeze.vmd + 사이드카 반영(미리보기만 한 프리셋은 미포함 —
의도된 설계).
